🏡 House Warming Invitation Website

📌 About the Project

This is a simple and beautiful House Warming Invitation Website created using HTML and CSS.

The website is designed to invite friends and family members to celebrate a new home and its house warming ceremony.

✨ Features

* Beautiful invitation design
* Elegant colors and layout
* House warming event details
* Date, time and venue information
* Location button
* Responsive design for mobile devices

🛠️ Technologies Used

* HTML5
* CSS3
